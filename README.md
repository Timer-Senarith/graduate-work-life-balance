# Graduate Student Work-Life Balance

Python analysis of 200 simulated graduate student survey responses.

## Technical Skills
- Python, NumPy, pandas, Matplotlib
- Survey design and hypothesis development
- Proportionate stratified random sampling
- Reproducible data simulation
- Data cleaning and validation
- Missing-value handling
- Boolean filtering and categorical grouping
- Descriptive statistics and data visualization
- CSV import and export

## Analysis Performed
- Checked duplicates, missing values, and rating ranges
- Calculated means, medians, standard deviations, and quartiles
- Summarized response frequencies and percentages
- Compared low work-life balance across paid work-hour groups
- Repeated comparisons by enrollment status
- Calculated the percentage reporting frequent stress
- Summarized preferred university support options
- Created a bar chart and exported summary tables

## Run
pip install numpy pandas matplotlib
python3 ALY6105_Module6_Simple.py

All data are simulated. Results do not represent actual Northeastern students or establish causation.
